# Speedrun-Ethereum-Fast-Tracking-Web3-Development-for-Builders
Speedrun Ethereum: Fast-Tracking Web3 Development for Builders
Speedrun Ethereum is a hands-on learning platform designed to teach developers how to build on Ethereum through a series of interactive challenges. Created by the BuidlGuidl community, it uses the powerful Scaffold-ETH 2 framework to help developers go from zero to dApp in record time.
Each challenge is a mini-project that teaches a core concept of Ethereum development — from minting NFTs to building decentralized exchanges (DEXs), stablecoins, lending platforms, and prediction markets.
